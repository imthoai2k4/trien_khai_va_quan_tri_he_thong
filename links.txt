IV. HỆ THỐNG LOG TẬP TRUNG (Centralized Logging - Loki & Promtail)
--------------------------------------------------------------------------------
* Loki và Promtail KHÔNG mở cổng ra host (chỉ chạy trong mạng nội bộ), nên toàn
  bộ log được xem và truy vấn gián tiếp qua Grafana Explore:

  http://localhost:3001/explore
  - Đăng nhập: admin / admin
  - Chọn datasource: Loki
  - Dán truy vấn LogQL vào ô Query rồi bấm "Run query"

* Các câu truy vấn LogQL mẫu (minh chứng Task 13):
  1. Toàn bộ log ứng dụng đặt vé:
     {service="movie-app"}

  2. Lọc lỗi hệ thống / HTTP >= 400:
     {service="movie-app"} |= "error"
     {service="movie-app"} | json | status >= 400

  3. Sự kiện nghiệp vụ Đặt vé / Thanh toán:
     {service="movie-app"} | json | type="booking_event"
     {service="movie-app"} | json | type="payment_event"

  4. Truy vấn bổ sung:
     {service="nginx"}                                              (log Nginx)
     {service="mysql"}                                              (log MySQL)
     {service="movie-app", level="error"}                           (chỉ log lỗi)
     sum by (service) (count_over_time({service=~".+"}[1m]))        (mật độ log)
