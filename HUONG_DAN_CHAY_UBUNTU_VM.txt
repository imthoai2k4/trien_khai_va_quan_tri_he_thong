HUONG DAN CHAY TKPM TREN UBUNTU SERVER (VMWARE)
================================================

1. KHOI DONG DU AN

  1) Mo VMware Workstation.
  2) Bat may ao Ubuntu Server.
  3) Cho Ubuntu khoi dong xong. Docker Engine va cac container TKPM duoc cau
     hinh tu khoi dong lai tu dong.
  4) Mo cac link o muc 3 tren Windows hoac may trong mang co the truy cap VM.

Neu cac container chua tu chay, dang nhap Ubuntu va chay:

  cd ~/TKPM
  docker compose up -d

Kiem tra trang thai:

  cd ~/TKPM
  docker compose ps

Xem log neu can:

  cd ~/TKPM
  docker compose logs -f

2. DUNG DU AN / TAT MAY AO

De dung cac container nhung giu may Ubuntu dang bat:

  cd ~/TKPM
  docker compose stop

De bat lai sau do:

  cd ~/TKPM
  docker compose up -d

Co the tat Ubuntu VM tu menu Shutdown cua Ubuntu/VMware. Khi bat lai may ao,
Docker se tu khoi dong cac container co restart policy. Neu chua thay dich vu,
chay lai `docker compose up -d` nhu muc 1.

may dang mo trinh duyet; tren Windows hay dung IP cua Ubuntu VM nhu cac link tren.
